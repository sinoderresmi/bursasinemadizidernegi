# SİNODER Website — GitHub Pages

## Yayına alma
1. GitHub'da yeni public repository açın (ör. `sinoder-web`).
2. `index.html`, `sinoder-logo.jpeg` ve `sinoder-konsept.jpeg` dosyalarını repo köküne yükleyin.
3. Repository > Settings > Pages bölümünde `Deploy from a branch` seçin; `main` ve `/ (root)` seçip Save'e basın.
4. Birkaç dakika içinde GitHub Pages adresiniz yayınlanır.

## Yayından önce tamamlanması gerekenler
- `index.html` içindeki `const IBAN = "";` alanına doğrulanmış IBAN girin. Sayfada görünen TR00… numarası yalnızca örnektir, ödeme yapmayın.
- Banka adı/şube, merkez adresi, e-posta, sosyal medya bağlantıları ve KVKK metinlerini ekleyin.
- Bağış Yap butonu şu an WhatsApp bilgi hattına yönlenir; gerçek bağış/ödeme bağlantısı varsa URL değiştirilmeli.

## Bilinmesi gerekenler
Bu, GitHub Pages üzerinde yayınlanabilen responsive statik tanıtım sitesidir. GitHub Pages tek başına CMS/yönetim paneli, e-posta bildirimli form, üyelik veya ödeme altyapısı sunmaz. İçerik güncellemek için dosyayı GitHub'da düzenlemek gerekir. Mobil tarayıcı uyumludur; App Store/Play Store uygulaması olması için ayrıca uygulama paketi ve mağaza yayın süreci gerekir.
